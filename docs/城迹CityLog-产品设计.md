# 城迹 CityLog 产品设计

2026-11-13 · 配套文档：[[城迹CityLog-调研结论]] · UI 稿：https://claude.ai/artifact/PcA4aTSX36tH1NvqFdzjCB

## 一句话

帮家长带孩子把自己住的城市走遍、走深、走透的 App。AI 负责备课和讲解，地图记录走过的每一条路，每次出门留下一页日志。

- 名字：**城迹 CityLog**
- Slogan：**世面，就在家门口。**
- 备选：把一座城，走遍、走深、走透。／不比走多远，只比看多深。／See deeper, not farther.
- Logo：一张三折的纸质城市地图，一条虚线足迹，一个橙色落点。文件在 `~/github/citylog/design/logo-icon.svg` 和 `logo-horizontal.svg`。

## 给谁用

**核心用户：孩子 4 到 12 岁、住在大中城市的家长。** 他们认同“见世面”重要，周末愿意带孩子出门，但预算或假期有限，不想每次都去商场和游乐场。

他们现在的三个难处：

1. **不知道去哪。** 景点去过了，普通的街道看不出有什么可看。
2. **查资料太累。** 视频说“提前查好资料”，实际一次要花一两个小时，坚持不了几周。
3. **讲不出来。** 孩子问“这是什么”“为什么”，家长自己也不知道，或者知道但讲不成孩子能懂的话。

次要用户：新搬到一座城市的家庭；喜欢 Citywalk 的成年人（不专门为他们设计，但产品对他们也成立）。

## 核心循环

| 时间 | 用户做什么 | 产品做什么 |
|---|---|---|
| 周四 | 收到推送，挑一个主题 | 按住址、孩子年龄、没走过的路生成 3 个周末主题 |
| 出门前 | 读 5 分钟备课卡 | 一句话讲透、三站、两个问孩子的问题 |
| 路上 | 边走边听，看到什么拍什么 | 到站自动讲解；拍照识别并回答 |
| 路上 | 让孩子讲一遍 | 录音，转成文字 |
| 到家 | 看地图变黄，看日志 | 把新走的路涂亮；自动生成当天日志 |

设计这个循环时的判断：视频方法里最难坚持的是“查资料”和“讲出来”，交给 AI；最有成就感的是“用彩笔把路标出来”，做成首页。

## 功能

### 1. 我家的城市地图（首页）

- 走过的路涂成黄色。出门时记录轨迹并匹配到道路，也可以手动补涂以前走过的路。
- 显示各区、各街道的涂亮比例。
- 首页下方固定一张“本周末主题”卡片。

### 2. 周末主题

- 每周生成 3 个，标题是一个孩子会问的问题，例如“运河边为什么有工厂？”
- 每个主题标明镜头、地点、距离、时长、能新涂亮几条路、怎么去。
- 六个镜头，对应视频里的讲法：

| 镜头 | 讲什么 | 例子 |
|---|---|---|
| 历史 | 这条路、这块地方的来历 | 路名是怎么来的 |
| 人文 | 古建筑、住过的名人、老行当 | 老药铺、故居 |
| 产业 | 工厂、市场、港口为什么在这里 | 工业分布和产业构成 |
| 规划 | 城区和郊区为什么不一样 | 新城为什么建在江边 |
| 公共 | 政府机关和公共设施是干什么的 | 法院、消防站、水厂 |
| 自然 | 山、水、树和这座城市的关系 | 行道树为什么是这种树 |

- 用户也可以说“我想去某某地方”，让 AI 现出一个主题。

### 3. 备课卡

- 给家长看，5 分钟读完。
- 结构固定：一句话讲透 → 三站（每站一两句）→ 问孩子的问题。
- 三个年龄版本：4–6 岁、6–9 岁、9–12 岁。同一个事实，不同的讲法和问题。
- 每条内容标注依据；查不到可靠资料的地方直接写明。

### 4. 边走边讲

- 路上的界面只留两个大按钮：拍一拍、孩子来讲。
- 到站震动提醒，讲解默认语音播放，手机可以收起来。
- 新走的路实时涂亮。

### 5. 拍一拍

- 对着建筑、招牌、树、机器、路牌拍照，AI 用两三句话回答，结合当前位置和主题。
- 给出两个可以继续追问的问题。
- 可以存进当天的日志。

### 6. 孩子来讲

- 孩子用自己的话把今天看到的讲一遍，录音并转写。
- 这句话是日志的主角，也是家长最愿意分享的内容。
- 作用和视频里说的一样：能给同学讲清楚，才算真的看懂了。

### 7. 城市日志

- 每次出门自动生成一页：路线、距离、新涂亮的路、照片、听过的故事、孩子说的话。
- 可以生成分享图。
- 一年的日志汇成《城市之书》，可以付费印刷。

### 8. 我家

- 累计数据、各区涂亮比例、六个镜头各用了几次。
- 会员、实体地图、城市之书的入口都在这里，不打断出门流程。

## 设计原则

1. **路上少看屏幕。** 产品的目的是让家长和孩子看城市，不是看手机。出门后界面极简，讲解用听的。
2. **问题比知识重要。** 主题是问题，备课卡以问题结尾。家长负责提问，AI 负责兜底。
3. **孩子不需要账号。** 账号属于家长，孩子只有昵称和出生年份。轨迹、照片、录音默认只存本机。
4. **AI 说不准就直说。** 每条讲解标注依据，不编故事。
5. **零成本的感觉不能丢。** 不推荐收费景点，不接商家广告，主题默认是免费可达的街道和公共空间。

## 视觉

- 颜色取自纸质地图的图例：地图墨绿 `#0F4C45`（品牌色）、主干道黄 `#FFC531`（涂亮的路）、落点橙 `#FF6B4A`（当前位置和强调）、水系蓝 `#BCDCE6`、绿地 `#CDE5C2`。
- 主界面就是地图。卡片圆角大、留白多，文字少。
- 数字（公里、条数、百分比）用醒目的大字，给孩子看得懂的成就感。

## 待定的问题

1. ~~第一座城市选哪里？~~ 已定：上海和大阪。新的问题是大阪面向谁：住在关西的华人家庭，还是日本本地家庭。
2. 主体用个人还是公司？影响上架、备案和收款。
3. 定价（98 元/年、实体地图 39 元）是建议值，需要上线后测试。
4. 历史类内容的资料来源怎么建：先人工整理一批热门路线，还是全靠检索。
